# 墨韻課堂

國風潑墨、青綠山水與 Q 版書生風格的互動簡報網站。以 Nearpod 教學流程為功能參考，採原創介面與插畫。

## 啟動

需要 Node.js 22 以上，JavaScript 無第三方套件。PDF 轉換需 Poppler（pdfinfo、pdftoppm）；PPT/PPTX 轉換需 LibreOffice。此電腦已完成安裝及中文轉換驗證。

其他環境請安裝 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/) 與 Poppler，將 SOFFICE_PATH 環境變數設為 soffice 執行檔路徑。本機預設使用專案 .tools/LibreOffice.app/Contents/MacOS/soffice；轉換引擎與上傳資料不納入 Git。

```sh
cd ~/projects/moyun-classroom
npm start
```

瀏覽 http://localhost:4178 。同一區域網路的學生可使用此電腦的區網 IP 與 4178 連接埠，視防火牆及校園網路隔離設定而定。從區網網址開啟教師端後複製的連結才適合分享給其他裝置。localhost 連結僅供本機測試。

## 使用

1. 選擇範例教材或建立新課堂。
2. 編輯頁面與活動，資料自動儲存在此瀏覽器。可下載 JSON 備份。按「上傳 PDF／PPT／圖片」即可逐頁匯入；選中任一頁後按「在此頁後插入互動」。
3. 教師按開始授課，取得六位數代碼與入課連結。
4. 學生輸入代碼與暱稱。可用另一個分頁在同一電腦測試。
5. 教師控制頁次，學生回應每 1.2 秒同步到教師端。
6. 公布答案停止收件；便利貼公布後全班可見。
7. 課堂結束前後均可匯出 CSV，請在關閉伺服器前匯出。

## 已實作

- 內容簡報、多頁編輯與順序調整，無固定頁數上限。
- PDF、PPT、PPTX、PNG、JPG、WebP、GIF 上傳；原稿逐頁轉成靜態頁面。
- 多筆型手寫：原子筆、鉛筆、毛筆、螢光筆、橡皮擦、筆色、粗細、復原／重做。
- 上傳頁改成手寫互動可在底圖作答；教師可書寫並按「分享教師筆跡」。
- 選擇題、投票、開放式問題、單欄填空與便利貼。
- YouTube 影片嵌入、https 外部資源連結。
- 教師開課、學生代碼加入、頁次同步、回應統計。
- 教師權限驗證；未公布的測驗答案不傳給學生端。
- CSV 作答匯出、教材 JSON 備份與匯入。
- 三份示範教材、響應式排版及鍵盤焦點。

## 邊界

這是可操作原型，尚未部署正式網路服務。課堂與回應存於伺服器記憶體，重啟或六小時沒有操作即清除。教材只存於瀏覽器，請備份。加入人數是累計值，不代表即時在線。

尚未實作帳號、持久化資料庫、班級名冊、學生自主進度、Google 簡報外掛、配對、拍照、記憶牌卡、專用闖關計分、3D 及全景檢視器。PhET/Sway 仍以連結開啟。

公開正式部署前需補上教師登入、課堂資料持久化、建立與加入教室的速率限制、TLS 與資料保留政策。本版已移除 30 頁、100 間教室與每間 100 人的固定限制。已驗證 132 頁、121 名加入者與超過 100 間教室；非無限容量保證，也不是並發壓力測試。記憶體、磁碟、瀏覽器儲存與網路仍是實際限制。

Google Fonts 需連網，離線會使用系統字型。影片與外部資源依對方網站政策提供。

## 驗證

```sh
npm test
```

使用 Node.js 內建測試器。涵蓋答案保護、教師授權、切頁競態、重複送出、填空判分、便利貼公布、報告及結課。Chrome UI 驗證紀錄見 [docs/驗證紀錄.md](docs/驗證紀錄.md)。

## 上傳與手寫資料

- 預設單一檔案 200 MB，MAX_UPLOAD_BYTES 可調；JSON 請求預設 64 MB，MAX_JSON_BYTES 可調。這是容量保護，不是頁數或連線數限制。
- 原稿、轉換頁面與手寫圖片存於 data/（可用 DATA_DIR 改位置），不送到外部轉換服務，不納入 Git。請連同 data/ 備份；教材 JSON 只含圖片路徑，單獨帶到另一台主機不含圖片。
- 轉換使用序列工作佇列，UI 可背景處理；PPT 動畫、影片與原稿文字編輯能力不會保留。字型缺少時可能替代字型，應檢查重要教材。
- 畫布草稿於分頁生命週期內保留；送出後有 PNG，重新整理可繼續在該 PNG 上加筆，但原有筆跡已平面化。
- 上傳與手寫檔目前不自動刪除；課堂記憶體仍於重啟或六小時無操作後清除。
- 檔案使用不可預測的資源網址，尚未做帳號層級的檔案權限；目前供可信區網原型使用，正式公開服務前需加入登入、儲存配額、轉檔隔離與保留政策。
