# 墨韻課堂

國風潑墨、青綠山水與 Q 版書生風格的互動簡報網站。以 Nearpod 教學流程為功能參考，採原創介面與插畫。

## 啟動

需要 Node.js 22 以上，JavaScript 無第三方套件。預設以 Docker 隔離執行 Poppler／LibreOffice，見 [部署說明](deploy/README.md)。可信本機測試可顯式設定 DEVELOPMENT_LOCAL_CONVERTER=1 使用已安裝引擎；正式環境不可啟用此模式。

其他環境請安裝 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/) 與 Poppler，將 SOFFICE_PATH 環境變數設為 soffice 執行檔路徑。本機預設使用專案 .tools/LibreOffice.app/Contents/MacOS/soffice；轉換引擎與上傳資料不納入 Git。

```sh
cd ~/projects/moyun-classroom
npm start
```

瀏覽 http://localhost:4178 。同一區域網路的學生可使用此電腦的區網 IP 與 4178 連接埠，視防火牆及校園網路隔離設定而定。從區網網址開啟教師端後複製的連結才適合分享給其他裝置。localhost 連結僅供本機測試。

## 使用

1. 先按「教師登入」，再選擇範例教材或建立新課堂。
2. 編輯頁面與活動，資料自動儲存在此瀏覽器。可下載包含圖片素材的完整 JSON 備份。按「上傳 PDF／PPT／圖片」即可逐頁匯入；選中任一頁後按「在此頁後插入互動」。
3. 教師按開始授課，取得六位數代碼與入課連結。
4. 學生輸入代碼與暱稱。可用另一個分頁在同一電腦測試。
5. 教師控制頁次，學生回應每 1.2 秒同步到教師端。
6. 公布答案停止收件；便利貼公布後全班可見。
7. 課堂結束前後均可匯出 CSV，並可匯出含圖片的完整作答 JSON；建議每次授課後備份。

## 已實作

- 內容簡報、多頁編輯與順序調整，無固定頁數上限。
- PDF、PPT、PPTX、PNG、JPG、WebP、GIF 上傳；原稿逐頁轉成靜態頁面。
- 多筆型手寫：原子筆、鉛筆、毛筆、螢光筆、橡皮擦、筆色、粗細、復原／重做。
- 上傳頁改成手寫互動可在底圖作答；教師可書寫並按「分享教師筆跡」。
- 選擇題、投票、開放式問題、單欄填空與便利貼。
- YouTube 影片嵌入、https 外部資源連結。
- 教師開課、學生代碼加入、頁次同步、回應統計。
- 教師權限驗證；未公布的測驗答案不傳給學生端。
- CSV 作答匯出、教材 JSON 備份與匯入。
- 三份示範教材、響應式排版及鍵盤焦點。

## 邊界

這是可操作原型，尚未部署正式網路服務。課堂與回應會以原子寫入方式保存至 DATA_DIR/classrooms.json，可於重啟後從「已儲存課堂」返回。編輯中的教材仍存於瀏覽器，請下載包含素材的完整備份。加入人數是累計值；教師學生狀態另顯示最近十秒是否有連線。

目前為單一教師管理密碼登入，尚未實作多教師獨立帳號、正式學籍名冊、學生自主進度、Google 簡報外掛、配對、拍照、記憶牌卡、專用闖關計分、3D 及全景檢視器。PhET/Sway 仍以連結開啟。

教師登入、課堂保存、建立／加入速率保護與圖片權限已實作；公開正式部署仍需可用主機、HTTPS 入口與隔離轉檔驗收。本版已移除 30 頁、100 間教室與每間 100 人的固定限制。已驗證 132 頁、121 名加入者與超過 100 間教室；非無限容量保證，也不是並發壓力測試。記憶體、磁碟、瀏覽器儲存與網路仍是實際限制。

Google Fonts 需連網，離線會使用系統字型。影片與外部資源依對方網站政策提供。

## 上傳與手寫資料

- 預設單一檔案 200 MB，MAX_UPLOAD_BYTES 可調；JSON 請求預設 64 MB，MAX_JSON_BYTES 可調。這是容量保護，不是頁數或連線數限制。
- 原稿、轉換頁面與手寫圖片存於 data/（可用 DATA_DIR 改位置），不送到外部轉換服務，不納入 Git。請連同 data/ 備份；新版「下載教材備份」會包含圖片內容並於還原時重新建立資源；舊版 JSON 仍只有路徑，需連同原 data/ 還原。
- 轉換使用序列工作佇列，UI 可背景處理；PPT 動畫、影片與原稿文字編輯能力不會保留。字型缺少時可能替代字型，應檢查重要教材。
- 文字與手寫草稿保存於此瀏覽器；新版手寫送出同時保存 PNG 與可編輯筆畫。舊版只有 PNG 的作品仍無法拆回個別筆畫。另有僅觸控筆模式與文字替代作答。
- 素材管理可將未使用檔案移入可還原回收區；課堂正在引用的圖片會阻止移除。回收區仍占用磁碟，營運者需訂定封存與清除期限。
- 圖片需教師登入或所屬課堂的學生權限；僅知道 UUID 網址不能讀取。轉檔預設使用無網路隔離容器，具佇列／磁碟配額；容器環境尚未完成此機實測，公開上線前必須驗收。

## 專家評估後修正

- 教師登入、登出撤銷控制權、已儲存課堂續課、圖片權限及跨站請求檢查。
- 完整素材備份還原、文字／筆畫草稿、未作答清單、個別回饋與作答次數。
- 學習目標、成功條件、解析、教材全文、基礎提示與進階挑戰。
- 教師頁面目錄、下一活動預覽、縮圖；影片播放／暫停控制及學生重新同步。
- 上傳取消、失敗檔重試、資源保護、可還原素材回收區。
- 單一教師密碼由 TEACHER_PASSWORD 注入；未設定時在 DATA_DIR/teacher-password 產生（權限600）。密碼不可公開。
- 預設只監聽127.0.0.1。公開服務須設定PUBLIC_ORIGIN=https網址並使用反向代理。

目前尚未正式部署。隔離容器、影片跨裝置播放、實體觸控筆與完整輔具驗收仍需完成。驗證詳見 docs/驗證紀錄.md。
