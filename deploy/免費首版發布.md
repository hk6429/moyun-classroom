# 免費首版發布紀錄

## 範圍

使用者已同意先上線 PDF／圖片版，PPT 直接匯入列為待辦；不新增付費訂閱。

## 正式入口

- Cloudflare：https://moyun-classroom.hk6429.workers.dev
- Netlify：https://moyun-classroom.netlify.app
- 共用 Turso：moyun-classroom（default 群組）。超額付費維持關閉。

## 本次修改

- 抽出 engine.mjs，共用既有課堂權限、控制與作答邏輯。
- Cloudflare API 使用 Turso 持久保存與版本比對重試，圖片分塊儲存；不使用 R2 或容器。
- PDF 在教師瀏覽器用 PDF.js 逐頁轉圖，逐頁上傳。取消或失敗後保留成功頁面，重試接續未完成頁次。
- 雙入口精確來源檢查、Secure／HttpOnly Cookie、圖片權限與回收區保護。
- 修正全域 submit 攔截導致對話框關閉無效的問題。
- 教師密碼以 CSPRNG 產生，部署於平台秘密；不納入 Git 或前端。

## 驗證

- 本機核心、雲端、權限、備份與雙站套件共 5 項整合測試通過。
- 正式 API：雙站教師登入、5 人並行加入、跨站文字／手寫回應、筆畫還原、PNG 位元組讀回、未授權圖片拒絕、學生控制拒絕、完整報告與已儲存課堂讀回。證據見 live-evidence.json。
- 實際 Chrome：Cloudflare 教師密碼登入成功；兩頁 PDF 範例匯入後，教材從 6 頁增為 8 頁；開課代碼 899403。
- 實際 Chrome：Netlify 以「跨站瀏覽器驗證」加入；教師名冊顯示 1 人在線；教師切至 PDF 頁後，學生端實際顯示同一張 PDF 圖片。

## 界線

目前是可試用的免費首版，不代表無限承載。API 單次資料 8 MB，免費平台有實際用量上限；未做長時間大型班級壓力驗證。教材草稿存於各瀏覽器，開課後課堂與作答才存於 Turso。PPT 直接匯入、實體觸控筆、完整輔具及各類 PDF 字型仍是後續驗證或開發項目。

## 重建

npm ci → npm run build:web → Wrangler 部署 → prepare-hosting 產生 Netlify 輸出 → Netlify 正式部署 → 正式讀回與瀏覽器驗證。詳見 README。
