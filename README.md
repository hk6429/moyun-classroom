# 墨韻課堂

國風潑墨、青綠山水與 Q 版書生風格的互動簡報網站。以 Nearpod 教學流程為功能參考，採原創介面與插畫。

## 啟動

需要 Node.js 22 以上，無需安裝套件。

```sh
cd ~/projects/moyun-classroom
npm start
```

瀏覽 http://localhost:4178 。同一區域網路的學生可使用此電腦的區網 IP 與 4178 連接埠，視防火牆及校園網路隔離設定而定。從區網網址開啟教師端後複製的連結才適合分享給其他裝置。localhost 連結僅供本機測試。

## 使用

1. 選擇範例教材或建立新課堂。
2. 編輯頁面與活動，資料自動儲存在此瀏覽器。可下載 JSON 備份。
3. 教師按開始授課，取得六位數代碼與入課連結。
4. 學生輸入代碼與暱稱。可用另一個分頁在同一電腦測試。
5. 教師控制頁次，學生回應每 1.2 秒同步到教師端。
6. 公布答案停止收件；便利貼公布後全班可見。
7. 課堂結束前後均可匯出 CSV，請在關閉伺服器前匯出。

## 已實作

- 內容簡報、多頁編輯與順序調整，最多 30 頁。
- 選擇題、投票、開放式問題、單欄填空與便利貼。
- YouTube 影片嵌入、https 外部資源連結。
- 教師開課、學生代碼加入、頁次同步、回應統計。
- 教師權限驗證；未公布的測驗答案不傳給學生端。
- CSV 作答匯出、教材 JSON 備份與匯入。
- 三份示範教材、響應式排版及鍵盤焦點。

## 邊界

這是可操作原型，尚未部署正式網路服務。課堂與回應存於伺服器記憶體，重啟或六小時沒有操作即清除。教材只存於瀏覽器，請備份。加入人數是累計值，不代表即時在線。

尚未實作帳號、持久化資料庫、班級名冊、學生自主進度、PPTX/PDF 檔案轉換、Google 簡報外掛、配對、手寫拍照、記憶牌卡、專用闖關計分、3D 及全景檢視器。外部 PDF/PhET/Sway 僅以連結開啟。

公開正式部署前需補上教師登入、課堂資料持久化、建立與加入教室的速率限制、TLS 與資料保留政策。本版限制 100 間教室、每間 100 人；尚未進行負載測試。

Google Fonts 需連網，離線會使用系統字型。影片與外部資源依對方網站政策提供。

## 驗證

```sh
npm test
```

使用 Node.js 內建測試器。涵蓋答案保護、教師授權、切頁競態、重複送出、填空判分、便利貼公布、報告及結課。Chrome UI 驗證紀錄見 [docs/驗證紀錄.md](docs/驗證紀錄.md)。

## 專案結構

- server.mjs：HTTP 伺服器及教室 API。
- public/：HTML、CSS、JavaScript 與原創 SVG 插畫。
- tests.mjs：伺服器整合測試。
- docs/功能對照.md：講義 21 項功能對照。
